# DrawPredictor

DrawPredictor je aplikace pro predikci fotbalových remíz založená na statistických datech, kurzech bookmakerů a strojovém učení.

## Cíl projektu

Vytvořit systém, který:

- analyzuje fotbalové zápasy,
- vypočítá pravděpodobnost remízy,
- identifikuje value příležitosti,
- průběžně se učí z výsledků.

## Technologie

- C#
- .NET
- ASP.NET Core
- Blazor
- PostgreSQL
- GitHub
